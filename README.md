# Vision24 - The First Smart Mirror in Kosovo 🇽🇰

![Vision24 Banner](/public/vision24Logo.png)

**Vision24** is the first premium brand bringing high-tech, luxury smart mirrors to the Kosovo market. Our web application serves as a sleek, modern showroom designed to convert visitors into customers through a bilingual interface (English/Albanian) and direct WhatsApp integration.

## 🌟 Key Features

* **🌍 Bilingual Support:** Instant toggling between **English** and **Albanian (Shqip)** to serve the local market.
* **📱 Smart OS Preview:** A visual simulation of the mirror's interface (Weather, Spotify, Calendar widgets).
* **💬 Direct Sales Channel:** Integrated floating **WhatsApp** button for instant "Cash on Delivery" orders in Kosovo.
* **🎨 Premium UI:** Built with **Tailwind CSS** for a dark, luxury aesthetic (Dark Mode) that mimics the mirror's actual reflection.
* **⚡ High Performance:** Powered by **React + Vite** for instant loading speeds.

## 🛠️ Tech Stack

* **Framework:** React 18
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **Hosting:** Google Firebase Hosting

## 🚀 Quick Start

To run this project locally on your machine:

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/arberberiisha/vision24.git](https://github.com/arberberiisha/vision24.git)
    cd vision24
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Run Development Server**
    ```bash
    npm run dev
    ```
    Open `http://localhost:5173` to view it in the browser.

## 📦 Deployment

This project is configured for **Google Cloud / Firebase Hosting**.
